# 谈薪：收集信息、给区间、应对压价

谈薪不是「报一个数」，而是用信息换取更好的总包。本页只提供信息框架与话术，**不替用户承诺或接受任何 offer**。

## 1. 先收集信息

| 信息 | 来源 | 用途 |
|---|---|---|
| 目标职级与带宽 | 招聘 JD、HR 初筛、内推朋友、公开薪资站 | 判断报价是否离谱 |
| 当前总包结构 | 用户提供：base、年终、股票、补贴 | 计算涨幅与平薪底线 |
| 市场分位 | 同城同岗同年限的 3–5 个样本 | 给出区间而不是单点 |
| 竞争 offer | 用户手上的其他流程 | 增加谈判筹码，不要虚构 |
| 非现金项 | 签字费、 relocation、股票、假期、远程 | 现金谈不动时换维度 |

**不要**让用户虚报当前薪资。背调、社保、个税记录都可能核对，虚报的代价远大于收益。

## 2. 报价顺序

1. **先问范围**：`这个职级的薪资带宽大概是多少？`
2. **再问结构**：`总包由哪几部分组成？年终与股票的发放规则是什么？`
3. **后给区间**：区间下限 = 用户可接受的目标，上限 = 略高于目标但可解释。
4. **不主动报当前薪资**：如果必须报，报总包结构，不报单一 base。

区间示例：

```text
期望总包 45–55 万，具体看职级与股票比例；
如果 base 比例更高，可以在总包上更灵活。
```

区间要有依据：同城同岗样本、当前总包、竞争 offer。没有依据的区间会被压到下限。

## 3. 常见压价话术与应对

| 对方说 | 目的 | 应对 |
|---|---|---|
| 我们预算有限 | 锚定低区间 | 问「这个职级的带宽是多少」，再谈非现金项 |
| 你期望多少 | 让你先出牌 | 反问职级与预算，再给有依据的区间 |
| 你现在的薪资是多少 | 用现状锚定 | 说明期望总包与结构，强调岗位价值而非现状 |
| 最多只能给到 X | 试探底线 | 确认是否书面、是否有签字费/股票/调薪节点 |
| 先入职，半年后调 | 延迟兑现 | 要求写入 offer 或补充协议，否则按当前数字评估 |
| 别人都接受这个数 | 从众压力 | 回到市场样本与个人匹配度，不被个案带走 |
| 你更看重成长吧 | 用价值观换钱 | 成长与报酬不冲突，明确两者都要 |
| 明天必须答复 | 压缩决策时间 | 要求书面 offer 与合理考虑期，不接受口头催促 |

## 4. 谈判维度

现金谈不动时，按优先级换维度：

1. 签字费（一次性，不影响薪资带宽）
2. 股票/期权（问清归属周期与回购条款）
3. 职级（影响长期带宽）
4. 年终保底（写入 offer）
5. 调薪节点（入职后 6 个月 review）
6. 远程/弹性、假期、培训预算

## 5. 决策框架

| 情况 | 建议 |
|---|---|
| 总包达到目标区间中位，职级匹配 | 可以接受，确认书面条款 |
| 总包低于目标但职级更高 | 评估 1–2 年后的带宽，不只看第一年 |
| 只有口头承诺 | 要求书面，口头不算数 |
| 对方持续压价且不愿给结构 | 视为信号，重新评估团队与岗位 |
| 有竞争 offer | 如实说明，不虚构数字，给对方合理时间 |

## 6. 硬边界

1. **不替用户承诺**「这个数可以接」「对方一定会给」。
2. **不指导虚报**当前薪资、职级、竞争 offer。
3. **不鼓励撕毁**已签的 offer 或劳动合同。
4. **提醒书面化**：所有关键条款（总包、股票、签字费、调薪节点）必须出现在 offer 或补充协议里。
5. **提醒税务与合规**：股票、签字费的计税方式不同，建议咨询专业人士。
