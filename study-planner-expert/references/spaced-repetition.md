# 间隔重复：SM-2 变体参数说明

遗忘是默认状态，复习不是「再学一遍」，而是在**快要忘的时候**重新提取一次。间隔重复解决的就是「什么时候复习」。

## 1. 基本原理

- 每次成功提取会延长下一次的复习间隔；提取失败则缩短。
- 间隔太短浪费时间，太长则遗忘后等于重学。
- 关键不是总复习次数，而是**在遗忘边缘复习**。
- 主动回忆（做题、复述、默写）比被动重读有效。

## 2. SM-2 变体的四个参数

| 参数 | 含义 | 初始值 | 调整规则 |
|---|---|---|---|
| `interval` | 当前间隔天数 | 1 | 成功：1 → 6 → interval × ease；失败：回到 1 |
| `ease` | 易度因子，越大间隔增长越快 | 2.5 | 按 grade 调整，下限 1.3 |
| `repetitions` | 连续成功次数 | 0 | 成功 +1；失败清零 |
| `mastery` | 掌握度，0–1 | 0.5 | 每次按 (grade − 3) × 0.15 调整 |

### ease 调整公式

```text
ease' = ease + (0.1 - (5 - grade) × (0.08 + (5 - grade) × 0.02))
```

| grade | ease 变化 |
|---|---|
| 5 | +0.10 |
| 4 | 0.00 |
| 3 | −0.14 |
| 2 | −0.32 |
| 1 | −0.54 |
| 0 | −0.80 |

下限 1.3：再低会让间隔增长过慢，复习量失控。

### interval 规则

- 第一次成功：1 天
- 第二次成功：6 天
- 之后：`round(interval × ease)`
- 任何一次失败：`interval = 1`，`repetitions = 0`

## 3. grade 评分标准

| grade | 含义 | 典型表现 |
|---|---|---|
| 5 | 完美 | 立刻答出，能举一反三 |
| 4 | 正确 | 稍作思考后答对 |
| 3 | 勉强 | 答对但很吃力，或漏掉细节 |
| 2 | 错误但熟悉 | 答错，但看答案后能理解 |
| 1 | 错误 | 答错，只记得一点 |
| 0 | 完全忘记 | 像第一次见 |

评分要诚实：每次都打 5，间隔会迅速拉长，结果是大面积遗忘。宁可打 3，让间隔保守一些。

## 4. 复习失败如何降档

单次失败：

- interval 回到 1 天，明天再复习。
- ease 下调，后续间隔增长变慢。
- mastery 下调，低于 0.4 时标记为「薄弱」。

连续两次失败：

- 暂停新增内容 1–2 天，先补这个知识点。
- 把卡片拆小：一张卡只考一个点。
- 换一种提问方式（从「是什么」改成「怎么用」「和 X 有什么区别」）。

连续三次失败：

- 判断是卡片设计问题还是基础缺失。
- 卡片太大就拆分；基础缺失就回到前置知识。
- 不要继续加复习次数，先解决理解问题。

## 5. 每日工作流

1. 打开 `records.json`，跑 `python3 scripts/review_schedule.py --records records.json --days 7`。
2. 按当天清单逐张复习，先主动回忆再看答案。
3. 每张卡复习后立即记录：`--advance <id> --grade <0-5>`。
4. 新学的知识点当天建卡，`due` 设为当天或次日。
5. 每周看一次逾期数量；逾期持续增长说明每日新卡太多。

## 6. 示例

```text
卡片：二分查找的循环终止条件
初始：interval=1, ease=2.5, repetitions=0, mastery=0.5

第 1 次 grade=5 → interval=1, ease=2.6, mastery=0.8
第 2 次 grade=4 → interval=6, ease=2.6, mastery=0.95
第 3 次 grade=3 → interval=16（6 × 2.6 取整）, ease=2.46, mastery=0.95
第 4 次 grade=2 → interval=1, ease=2.14, repetitions=0, mastery=0.8
```

## 7. 常见误区

- **只做新卡不复习**：欠账越滚越大，最后放弃。
- **复习等于重读**：重读的提取强度低，要做题或复述。
- **卡片太大**：一张卡塞一个章节，复习时无法判断会不会。
- **grade 虚高**：为了少复习打 5，结果全部遗忘。
- **每天新卡太多**：新卡上限应按复习负载动态调整，通常每天 10–30 张。
- **忽略逾期**：逾期卡片会挤占当天计划，必须优先清理。
