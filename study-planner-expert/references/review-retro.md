# 周复盘与中断重启

计划能不能持续，取决于复盘质量，而不是初始计划多完美。复盘的目标是**下周少犯同一个错**，不是给自己打分。

## 1. 周复盘四步

### 第一步：统计完成率

```text
完成率 = 实际完成任务数 / 计划任务数
```

同时记录：

- 计划总时长 vs 实际总时长
- 完成的任务里，有多少有验收物
- 逾期卡片数量变化

### 第二步：卡点分类

| 卡点类型 | 表现 | 调整方向 |
|---|---|---|
| 任务太大 | 一项任务拖了 3 天 | 拆成 30–50 分钟的小块 |
| 时间估计错误 | 计划 1 小时，实际 3 小时 | 按历史数据乘 1.5 重新估 |
| 没有反馈 | 做完不知道对不对 | 加验收物或找反馈来源 |
| 环境干扰 | 总被消息打断 | 换地点、断网、固定时段 |
| 动力不足 | 不想开始 | 降低启动门槛，先做 10 分钟 |
| 目标不真实 | 每周都完不成 | 下调里程碑或延长截止 |

### 第三步：只定 3 个调整项

调整项必须可执行、可验证：

- 好：`把数学任务从 90 分钟拆成两个 45 分钟块`
- 好：`每天晚上 8 点前完成单词复习`
- 差：`下周更努力`
- 差：`提高效率`

### 第四步：更新下周计划

- 完成率 ≥80%：保持任务量，或每周只加 1 个小任务。
- 完成率 60%–80%：维持任务量，先修卡点。
- 完成率 <60%：**减任务**，不减复盘；不要用加时长解决。

## 2. 完成率背后的信号

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 完成率高但验收全没过 | 任务太简单或验收标准太松 | 提高验收标准 |
| 完成率低但每天都在学 | 计划量超出真实时间 | 按真实时间重排 |
| 只完成简单任务 | 畏难，回避核心任务 | 把核心任务放在一天最早的时段 |
| 复习卡片全逾期 | 新卡太多或复习时间没排 | 降新卡量，固定复习时段 |
| 连续两周下降 | 目标或方法有问题 | 回到诊断，调整画像与里程碑 |

## 3. 中断重启策略

中断 ≥3 天时，**不要要求补完所有欠账**。欠账式补课会引发第二次放弃。

### 三天重启法

```text
第 1 天：只做复习，不做新内容（20–30 分钟）
第 2 天：恢复最小任务量（原计划的一半）
第 3 天：回到正常任务量的 80%
第 4 天起：回到原计划，但先检查里程碑是否需要顺延
```

### 重启时的三个决定

1. **欠账怎么处理**：只保留最近 3 天的错题/卡片，其余标记「已过期」，不补。
2. **里程碑是否顺延**：中断超过一周，里程碑截止顺延，不要压缩后续阶段。
3. **计划是否减量**：连续两次中断，说明原计划超出真实时间，直接减 20%–30%。

### 中断原因对应

| 原因 | 重启动作 |
|---|---|
| 生病/家庭事务 | 完全恢复后再重启，不设补课 |
| 工作加班 | 改用碎片时间做复习，深度任务周末补 |
| 动力崩溃 | 先做 10 分钟最小任务，恢复节奏再谈目标 |
| 计划太难 | 降一档任务量，重设验收标准 |
| 目标动摇 | 回到诊断卡，确认是否还要这个目标 |

## 4. 周复盘模板

```text
第 N 周复盘（日期）

完成率：18/24（75%）
计划时长：12 小时；实际：9.5 小时
逾期卡片：从 5 张降到 2 张

做得好的：
- 每天早上先做数学，核心任务没被挤掉

卡点：
1. 英语听力任务每次拖到晚上，最后跳过（任务太大 + 时段不对）
2. 周三加班后没有缓冲，整周节奏乱了

下周 3 个调整：
1. 听力拆成 15 分钟精听 × 2，放在通勤
2. 周三设为缓冲日，只排复习
3. 新卡从每天 20 张降到 15 张

里程碑：无需调整
```

## 5. 复盘禁忌

- 用「不够努力」解释所有问题。
- 只看完成率，不看验收质量。
- 一次改 5 个以上变量，无法判断哪个有效。
- 把复盘写成流水账，没有结论。
- 中断后先补课，结果再次崩盘。
- 用延长学习时间解决计划设计问题。
