# 计划质量检查清单

一份能执行的计划，必须同时满足**量可控、块可做、结果可验、节奏可持续**。下面每一条都能用 `scripts/plan_check.py` 自动检查。

## 1. 五条硬指标

| 指标 | 标准 | 为什么 |
|---|---|---|
| 每日任务数 | ≤3 件 | 超过 3 件，优先级会失效，完成率骤降 |
| 单块时长 | ≤50 分钟 | 注意力与记忆编码的最佳区间，长块需要拆分 |
| 单日总时长 | ≤真实可用时长 | 按名义时间排计划必然崩盘 |
| 验收物 | 每天至少 1 个 | 没有验收物就无法判断是否学会 |
| 缓冲日 | 每周至少 1 天 | 吸收加班、生病、突发任务 |

## 2. 任务写法

好任务同时包含**动作 + 对象 + 数量/时长 + 验收**：

```text
- [ ] 数学：高数极限章节，做 15 道基础题（45 分钟）
产出：15 题中至少 12 题独立做对
```

坏任务：

```text
- [ ] 学数学
- [ ] 看英语
- [ ] 复习专业课
```

坏在哪里：不知道做什么、做多少、什么时候算完成。

## 3. 验收物类型

| 类型 | 例子 |
|---|---|
| 正确率 | 20 题正确率 ≥80% |
| 产出物 | 1 页错题总结、1 个可运行 demo |
| 复述 | 不看资料讲清 3 个概念 |
| 限时结果 | 60 分钟内完成一套阅读 |
| 外部反馈 | 老师批改、同行 review、用户试用 |

验收物必须是**当天能检查**的，不能写「以后能用上」。

## 4. 周计划模板

```text
# 第 N 周计划

本周目标：完成 XXX，验收标准：YYY
可用时间：工作日 1 小时，周末 2 小时

## 周一
- [ ] 任务 A（45 分钟）
- [ ] 任务 B（20 分钟）
产出：……

## 周二
- [ ] 任务 C（50 分钟）
- [ ] 复习昨日错题（20 分钟）
产出：……

## 周三（缓冲）
- [ ] 只做复习（30 分钟）
产出：清理逾期卡片

## 周四至周六
（同上，每天 ≤3 件）

## 周日
- [ ] 本周复盘（30 分钟）
- [ ] 下周计划（20 分钟）
产出：复盘记录 + 下周 3 个调整
```

## 5. 最小可行计划

时间很少时（每天 30–45 分钟），保留三件事：

1. **一个核心任务**（25–40 分钟）
2. **一个复习任务**（10–15 分钟）
3. **一个验收动作**（2 分钟记录结果）

宁可每天只完成 1 件核心任务，也不要排 5 件然后全部放弃。

## 6. 计划检查清单

- [ ] 每天任务 ≤3 件
- [ ] 每个任务有明确时长
- [ ] 单块 ≤50 分钟
- [ ] 单日总时长 ≤真实可用时长
- [ ] 每天有验收物
- [ ] 每周有缓冲日
- [ ] 有固定复习安排
- [ ] 任务动词具体（做、写、背、练、测），不是「学」「看」
- [ ] 计划里没有「补完所有欠账」这类不可完成任务
- [ ] 里程碑有截止周与验收标准

## 7. 常见失败模式

| 失败模式 | 表现 | 修正 |
|---|---|---|
| 排满主义 | 每天 6 件任务，第一周就崩 | 减到 3 件，留缓冲 |
| 时长幻觉 | 计划 2 小时，实际可用 45 分钟 | 按真实时间重排 |
| 无验收 | 每天都在学，不知道学会没有 | 每天加一个可检查的产出 |
| 无复习 | 学完就忘，反复从头开始 | 用 SM-2 排程 |
| 完美主义 | 一处没完成就整天放弃 | 允许 60% 完成，先保核心任务 |
| 只排新内容 | 欠账越滚越大 | 新内容与复习比例控制在 7:3 |
| 计划不可见 | 写完就忘 | 每天打开同一份计划并勾选 |
